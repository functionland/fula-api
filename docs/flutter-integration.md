# Flutter Integration Guide

This guide covers integrating Fula's encrypted decentralized storage with Flutter applications for both Android and Web platforms.

## Overview

Fula provides two integration options for Flutter:

1. **S3-Compatible SDK** (via `minio` package) - For basic storage operations
2. **Native Rust SDK** (via `fula_client` package) - For encrypted storage with client-side encryption, metadata privacy, and secure file sharing

The native SDK is recommended when you need:
- Client-side encryption (AES-256-GCM)
- Metadata privacy (obfuscated file names)
- Secure file sharing with capabilities
- Key rotation support
- WASM support for Flutter Web

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                    Flutter App                           │
│                  (Android / Web)                         │
├─────────────────────────────────────────────────────────┤
│              fula_client (Dart package)                  │
│           Auto-generated by flutter_rust_bridge          │
├────────────────────────┬────────────────────────────────┤
│       Android/iOS      │            Web                  │
│   flutter_rust_bridge  │    flutter_rust_bridge          │
│   (FFI via .so/.dylib) │    (WASM via wasm-bindgen)      │
├────────────────────────┴────────────────────────────────┤
│              crates/fula-flutter (Rust)                  │
│         Thin wrapper exposing simplified API             │
├─────────────────────────────────────────────────────────┤
│           fula-client + fula-crypto (existing)           │
│              (Same Rust code, all platforms)             │
└─────────────────────────────────────────────────────────┘
```

## Native SDK Setup

### Prerequisites

- Flutter 3.0+
- Rust toolchain (for building)
- Android NDK (for Android builds)

### Installation

#### Option 1: From pub.dev (Recommended)

```bash
flutter pub add fula_client
```

Or add to your `pubspec.yaml`:

```yaml
dependencies:
  fula_client: ^0.1.0
```

#### Option 2: From Git (Development)

```yaml
dependencies:
  fula_client:
    git:
      url: https://github.com/functionland/fula-api.git
      path: packages/fula_client
```

#### Option 3: Download Pre-built Binaries

Download from [GitHub Releases](https://github.com/functionland/fula-api/releases):
- `android-libs.zip` - Native libraries for Android
- `ios-libs.zip` - Native libraries for iOS
- `wasm-package.zip` - WASM bundle for web

### Android Configuration

Add to `android/app/build.gradle`:

```gradle
android {
    defaultConfig {
        ndk {
            abiFilters 'arm64-v8a', 'armeabi-v7a', 'x86_64'
        }
    }
}
```

### Web Configuration

For Flutter Web with WASM, ensure your web server serves WASM files with the correct MIME type:
```
application/wasm
```

## API Reference

### Configuration Types

#### FulaConfig
```dart
class FulaConfig {
  final String endpoint;        // Gateway URL (e.g., "http://localhost:9000")
  final String? accessToken;    // JWT authentication token
  final int timeoutSeconds;     // Request timeout (default: 30)
  final int maxRetries;         // Retry attempts (default: 3)
}
```

#### EncryptionConfig
```dart
class EncryptionConfig {
  final Uint8List? secretKey;           // 32-byte key (null = generate new)
  final bool enableMetadataPrivacy;     // Obfuscate file names (default: true)
  final ObfuscationMode obfuscationMode; // Deterministic or Random
}
```

### Creating Clients

#### Basic Client (No Encryption)
```dart
import 'package:fula_client/fula_client.dart';

final config = FulaConfig(
  endpoint: 'http://your-fula-gateway.com:9000',
  accessToken: 'your-jwt-token',
);

final client = await createClient(config);
```

#### Encrypted Client
```dart
final encryptionConfig = EncryptionConfig(
  enableMetadataPrivacy: true,
  obfuscationMode: ObfuscationMode.deterministic,
);

final encryptedClient = await createEncryptedClient(config, encryptionConfig);
```

### Bucket Operations

```dart
// Create a bucket
await createBucket(client, 'my-bucket');

// List all buckets
final buckets = await listBuckets(client);
for (final bucket in buckets) {
  print('Bucket: ${bucket.name}, Created: ${bucket.createdAt}');
}

// Check if bucket exists
final exists = await bucketExists(client, 'my-bucket');

// Delete a bucket
await deleteBucket(client, 'my-bucket');
```

### Object Operations (Unencrypted)

```dart
// Upload data
final data = utf8.encode('Hello, Fula!');
final result = await putObject(client, 'my-bucket', 'hello.txt', Uint8List.fromList(data));
print('ETag: ${result.etag}');

// Download data
final downloaded = await getObject(client, 'my-bucket', 'hello.txt');
print('Content: ${utf8.decode(downloaded)}');

// Get object metadata
final head = await headObject(client, 'my-bucket', 'hello.txt');
print('Size: ${head.size} bytes');

// List objects
final listResult = await listObjects(client, 'my-bucket', ListOptions(
  prefix: 'images/',
  maxKeys: 100,
));

// Delete object
await deleteObject(client, 'my-bucket', 'hello.txt');
```

### Encrypted Operations

```dart
// Upload with client-side encryption
final secretData = utf8.encode('Sensitive information');
final putResult = await putEncrypted(
  encryptedClient,
  'my-bucket',
  '/documents/secret.txt',
  Uint8List.fromList(secretData),
);

// Download and decrypt
final decrypted = await getDecrypted(
  encryptedClient,
  'my-bucket',
  '/documents/secret.txt',
);
print('Decrypted: ${utf8.decode(decrypted)}');

// List decrypted files (shows original names)
final files = await listDecrypted(encryptedClient, 'my-bucket', ListOptions());
for (final file in files) {
  print('File: ${file.originalKey}, Size: ${file.size}');
}
```

### Flat Namespace Operations

The flat namespace API provides a file-system-like interface with path-based access:

```dart
// Upload using file paths
await putFlat(encryptedClient, 'my-bucket', '/photos/vacation/beach.jpg', imageData, 'image/jpeg');
await putFlat(encryptedClient, 'my-bucket', '/photos/vacation/sunset.jpg', imageData2, 'image/jpeg');

// Download by path
final photo = await getFlat(encryptedClient, 'my-bucket', '/photos/vacation/beach.jpg');

// List directory structure
final listing = await listDirectory(encryptedClient, 'my-bucket', '/photos/');
for (final entry in listing.entries) {
  if (entry.isDirectory) {
    print('Directory: ${entry.name}/');
  } else {
    for (final file in entry.files) {
      print('  File: ${file.originalKey}');
    }
  }
}

// Delete by path
await deleteFlat(encryptedClient, 'my-bucket', '/photos/vacation/beach.jpg');
```

### Secure Sharing

Create and accept share tokens for secure file sharing. Note that since `fula-api` v0.3.0 (commit `9069817`) the `getWithShare` / `getWithToken` bindings take an additional `originalKey` argument so the recipient's client can enforce the token's `path_scope` — the share token granted by `create_share_token` sets `path_scope = storage_key` for FxFiles-style single-file shares, so `originalKey` and `storageKey` are typically the same value.

```dart
// Create a read-only share token (FxFiles defaults to path_scope = storage_key)
final shareToken = await createShareToken(
  encryptedClient,
  bucket,
  storageKey,
  recipientPublicKey,   // 32-byte X25519 public key
  null,                 // expiresAt: null = no expiration
);

// Create a time-limited share
final expiresAt = DateTime.now()
    .add(Duration(hours: 24))
    .millisecondsSinceEpoch ~/ 1000;
final temporalToken = await createShareTokenWithMode(
  encryptedClient,
  bucket,
  storageKey,
  recipientPublicKey,
  ShareMode.temporal,   // always resolves to the current version of the path
  expiresAt,
);

// Accept a share from someone else (parses the token locally; no network)
final acceptedShare = await acceptShare(encryptedClient, shareTokenJson);

// Get the file using the accepted share — 5-arg form since v0.3.0.
// originalKey must match (or be a prefix-match of) the token's path_scope.
final sharedData = await getWithShare(
  encryptedClient,
  'shared-bucket',
  storageKey,     // obfuscated CID-like storage key
  storageKey,     // originalKey: path_scope check is starts_with
  acceptedShare,
);

// Or the single-step helper (same 5-arg shape):
final sharedDataOneStep = await getWithToken(
  encryptedClient,
  'shared-bucket',
  storageKey,
  storageKey,
  shareTokenJson,
);

// Inspect the accepted share
final permissions = getSharePermissions(acceptedShare);
print('Can read: ${permissions.canRead}, Can write: ${permissions.canWrite}');
print('Valid: ${isShareValid(acceptedShare)}');
```

Since commit `9069817`, fula-flutter's `create_share_token` also stamps the content `encryption_version` (v4) into the token so the recipient knows to decrypt with AAD — if you see `decryption failed: aead::Error` on an old share, rebuild and re-issue the link with the current fula-flutter.

### Key Rotation

Rotate encryption keys for enhanced security:

```dart
// Create rotation manager
final rotationManager = createRotationManager(encryptedClient);

// Check KEK version for an object
final version = await getKekVersion(encryptedClient, 'my-bucket', storageKey);
print('Current KEK version: $version');

// Rotate a single object
final newVersion = await rewrapObject(
  encryptedClient,
  'my-bucket',
  storageKey,
  rotationManager,
);

// Rotate all objects in a bucket
final report = await rotateBucket(encryptedClient, 'my-bucket', rotationManager);
print('Rotated: ${report.rotated}/${report.total}');
print('Success rate: ${report.successRate()}%');
```

### Multipart Uploads

For large files, use multipart uploads with progress tracking:

```dart
// Start multipart upload
final upload = await startMultipart(client, 'my-bucket', 'large-file.zip');

// Upload parts
final chunkSize = 5 * 1024 * 1024; // 5MB chunks
for (var i = 0; i * chunkSize < data.length; i++) {
  final start = i * chunkSize;
  final end = min((i + 1) * chunkSize, data.length);
  final chunk = data.sublist(start, end);

  await uploadPart(upload, i + 1, Uint8List.fromList(chunk));
  print('Uploaded part ${i + 1}');
}

// Complete the upload
final etag = await completeMultipart(upload);
print('Upload complete: $etag');
```

### Key Export/Import

Export and import encryption keys for backup or cross-device sync:

```dart
// Export the secret key
final secretKey = exportSecretKey(encryptedClient);
// Store securely (e.g., in platform keychain)

// Create client with existing key
final restoredClient = await createEncryptedClient(
  config,
  EncryptionConfig(
    secretKey: secretKey,
    enableMetadataPrivacy: true,
  ),
);
```

## Error Handling

All operations can throw `FulaError` with specific error types:

```dart
try {
  final data = await getDecrypted(client, 'bucket', 'key');
} on FulaError catch (e) {
  switch (e) {
    case FulaError.notFound:
      print('Object not found: ${e.bucket}/${e.key}');
      break;
    case FulaError.accessDenied:
      print('Access denied: ${e.message}');
      break;
    case FulaError.network:
      print('Network error: ${e.message}');
      break;
    case FulaError.encryption:
      print('Encryption error: ${e.message}');
      break;
    default:
      print('Error: $e');
  }
}
```

## Complete Example

```dart
import 'dart:convert';
import 'dart:typed_data';
import 'package:flutter/material.dart';
import 'package:fula_client/fula_client.dart';

class FulaStorageDemo extends StatefulWidget {
  @override
  _FulaStorageDemoState createState() => _FulaStorageDemoState();
}

class _FulaStorageDemoState extends State<FulaStorageDemo> {
  EncryptedClientHandle? _client;
  List<FileMetadata> _files = [];
  bool _loading = true;

  @override
  void initState() {
    super.initState();
    _initClient();
  }

  Future<void> _initClient() async {
    final config = FulaConfig(
      endpoint: 'http://localhost:9000',
      accessToken: null,
      timeoutSeconds: 30,
      maxRetries: 3,
    );

    final encConfig = EncryptionConfig(
      secretKey: null, // Generate new key
      enableMetadataPrivacy: true,
      obfuscationMode: ObfuscationMode.deterministic,
    );

    _client = await createEncryptedClient(config, encConfig);

    // Ensure bucket exists
    try {
      await createBucket(_client!.client, 'demo-bucket');
    } catch (_) {
      // Bucket may already exist
    }

    await _refreshFiles();
  }

  Future<void> _refreshFiles() async {
    setState(() => _loading = true);

    final files = await listDecrypted(_client!, 'demo-bucket', ListOptions());

    setState(() {
      _files = files;
      _loading = false;
    });
  }

  Future<void> _uploadFile(String name, String content) async {
    final data = Uint8List.fromList(utf8.encode(content));
    await putFlat(_client!, 'demo-bucket', '/$name', data, 'text/plain');
    await _refreshFiles();
  }

  Future<String> _downloadFile(String path) async {
    final data = await getFlat(_client!, 'demo-bucket', path);
    return utf8.decode(data);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Fula Encrypted Storage')),
      body: _loading
          ? Center(child: CircularProgressIndicator())
          : ListView.builder(
              itemCount: _files.length,
              itemBuilder: (context, index) {
                final file = _files[index];
                return ListTile(
                  leading: Icon(Icons.lock),
                  title: Text(file.originalKey),
                  subtitle: Text('${file.size} bytes'),
                  trailing: Icon(Icons.download),
                  onTap: () async {
                    final content = await _downloadFile(file.originalKey);
                    ScaffoldMessenger.of(context).showSnackBar(
                      SnackBar(content: Text('Content: $content')),
                    );
                  },
                );
              },
            ),
      floatingActionButton: FloatingActionButton(
        onPressed: () async {
          await _uploadFile(
            'note_${DateTime.now().millisecondsSinceEpoch}.txt',
            'Created at ${DateTime.now()}',
          );
        },
        child: Icon(Icons.add),
      ),
    );
  }
}
```

## Platform-Specific Notes

### Android
- The native library is compiled for arm64-v8a, armeabi-v7a, and x86_64
- Minimum SDK version: 21
- Uses JNI via flutter_rust_bridge

### Web (WASM)
- Requires browser with WASM support (Chrome 57+, Firefox 52+, Safari 11+)
- Uses wasm-bindgen for Rust-JavaScript interop
- Async operations use JavaScript promises internally
- No tokio runtime; uses browser's async scheduler

## Security Considerations

1. **Key Storage**: Store encryption keys securely using platform keychains
2. **Transport**: Always use HTTPS for gateway connections in production
3. **Key Rotation**: Regularly rotate keys using the rotation API
4. **Metadata Privacy**: Enable for sensitive file names
5. **Share Expiration**: Use temporal shares with expiration for sensitive content

## Troubleshooting

### Build Issues

**Android NDK not found:**
```bash
export ANDROID_NDK_HOME=$ANDROID_HOME/ndk/VERSION
```

**WASM build fails:**
Ensure you have `wasm32-unknown-unknown` target:
```bash
rustup target add wasm32-unknown-unknown
```

### Runtime Issues

**"Library not loaded" on startup:**
Ensure the native library is included in your build. Check `android/app/src/main/jniLibs/`.

**CORS errors in web:**
Configure your Fula gateway to allow CORS from your Flutter web app's origin.
