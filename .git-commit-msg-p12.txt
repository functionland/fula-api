new, so dev/admin/all other constructors are untouched) plus
assert_mcp_scope(bucket, key, action) (None => Ok, byte-identical; Some =>
McpScope::assert mapped to opaque AccessDenied "out of MCP scope").
auth.rs gains mcp_scope_from_claims(&claims) which fail-CLOSES: an
MCP-flagged token (token_use=mcp_s3) with an absent/invalid mcp claim is
REFUSED, and (codex hardening) an mcp claim WITHOUT token_use=mcp_s3 is
rejected as ambiguous - neither falls through to broad storage access.
auth_middleware computes the scope before moving claims, sets it on the
session.
